# PROYECTO-FINAL:EcoLife AI
Descripción:
EcoLife AI es una aplicación que ayuda a las personas a reducir su impacto ambiental mediante inteligencia artificial, educación y gamificación.
La aplicación analiza los hábitos del usuario, calcula sus emisiones de CO₂, enseña a reciclar y reutilizar materiales, y recompensa cada acción ecológica con un sistema de puntos y logros.
Características
- Calculadora de huella de carbono.
- Reciclaje inteligente con reconocimiento de materiales.
- Chatbot ecológico (EcoBot) con consejos y noticias.
- Sistema de juego y recompensas.
- Cuestionarios sobre reciclaje, energías renovables y biodiversidad.
- Perfil ecológico con estadísticas de impacto ambiental.
