# PROYECTO-FINAL9
## Este es el tipo de mi proyecto:
> EcoLife AI es una aplicación que ayuda a las personas a reducir su impacto ambiental mediante inteligencia artificial, educación y gamificación. La aplicación analiza los hábitos del usuario, calcula sus emisiones de CO₂, enseña a reciclar y reutilizar materiales, y recompensa cada acción ecológica con un sistema de puntos y logros.
